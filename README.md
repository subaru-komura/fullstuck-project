## Getting Started

## Installation

1. Clone the repo

   `git clone https://github.com/subaru-komura/fullstuck-project.git`

2. Install NPM packages

   `npm install`

## Usage

1. set up DB

`cd db`
`npm run migrate`
`npm run seed`

2. start API

`cd src/backend`
`npm run start`

3. start APP

`npm run dev`  
access http://localhost:5173/
